src/account-store.ts: 官方 slot 共享的状态控制器，串行处理 Server、账号和插件动作并返回地址保存结果；服务/账号或连接边界变化时取消旧事实请求，防止迟到数据与错误跨会话回填；登录查询有截止时间；只读 `api` 端口让设置页与用量折叠块复用同一同源网络实例；失败码统一走 local-api 的 `enterpriseLocalErrorCode`，不再各写一份；宿主在 AUTHORIZING 下发的 `authorizeUrl` 只原样承载（不产生任何副作用，由登录弹窗消费）。

src/desktop-runtime.ts: 桌面运行时接缝，逐 app 特性检测而不假定一套通道：`enterpriseDesktopActions` 只认 `globalThis.dshDesktopActions.invoke`（fork 专有，Harness.app 0.2.0-rc.2 无此通道 → undefined）；`createEnterpriseUpdateSource` 以 `protocolVersion === 1 && typeof updates.open === 'function'` 判定可用，`status()` 只取一次初值、其后全由 `subscribe(cb)` 推送（不轮询、dispose 即取消订阅、订阅先到不被迟到的 status 覆盖），并严格解码 `{phase,version?,percent?,failure?}`、把九个官方 failure 码映射成官方中文文案；`runEnterpriseReload`/`runEnterpriseRestart` 是重载与重启唯一执行口径（invoke 拒绝或同步抛出时，重载回落页面重载、重启交回可见反馈），绝不退回自造 IPC 或同源 POST。

src/shortcuts-view.tsx: 「快捷键」入口的数据层与只读速查弹窗。数据源只有官方注册表这一条：读宿主 `shortcuts` 服务的 `catalog`/`fixedCatalog` 两个可观察目录（`ctx.inject(['shortcuts'])` 等一次服务出现、两个目录各自订阅、合并快照引用稳定、注销即释放），严格解码官方行并保留官方分组（未知分组显示原始 id，不编中文名）；注册表整体不可读时**只**展示 launcher props 的 `settingsShortcut` 并标注范围，绝不自造按键表、不注册按键、不装任何 document/window 级键盘监听（官方 `shortcuts.open` 已由官方自己绑定）；弹窗另带 `notice`/`onOpenSettings` 两个口子，reach-in 失败时在同一处展示「一览 + 引导」。
