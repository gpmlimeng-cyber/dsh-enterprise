## 这套手册怎么读

| 你的角色 | 从哪开始 | 你会得到什么 |
|---|---|---|
| 平台管理员 | 管理员手册 → 快速开始 → 控制台导览 | 能独立完成身份、成员、模型、授权、配额、插件的全套配置 |
| 模型管理员 | 管理员手册 → 模型与授权相关篇目 | 清楚供应商凭据边界、托管别名与授权/配额的区别 |
| 插件管理员 | 管理员手册 → 插件治理 | 会走完上传 → 发布 → 分配 → 客户端上报的闭环 |
| 审计员 | 管理员手册 → 角色与权限矩阵、用量与审计 | 明确自己能看什么、为什么看不到其它接口 |
| 员工 | 员工手册 | 在自己的 Desktop / Harness 里完成接入并日常使用 |
| 运维 | 运维手册 | 部署、备份、升级回滚与日常检查 |

> 💡 **手册与 API 参考的分工**：手册回答"我该点哪里、为什么这样配、报错先看什么"；
> API 参考回答"这个接口的字段是什么"。手册里凡涉及字段细节的地方，都会直接链到对应接口。

## 文档的可靠性

手册不是一次性写完就放着：

- **自动生成页**：角色与权限矩阵、配置项参考、错误码速查、界面地图都由运行实例或契约在构建期生成，
  不靠人工抄写（页头会标「自动生成」）。
- **漂移门禁**：每篇声明的 `sourceRefs` 必须仍然存在；正文里提到的界面按钮名必须仍能在控制台构建产物中找到；
  站内链接与锚点必须有效。任一不满足，构建直接失败。
- **校验时间**：每页页头显示最后人工校验日期，超过 90 天会标「待复核」。
