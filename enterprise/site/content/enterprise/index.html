ENTERPRISE

让每位员工用好 Agent，让企业始终掌握边界。

员工继续用自己熟悉的 Harness 工作区；组织在同一套系统里拿到统一身份、模型供给、额度治理与使用记录。 个人保持高效，组织获得秩序。

预约沟通 先看开源版

VALUE

把分散的 Agent 使用，变成可管理的组织能力

01

统一身份与组织权限

对接既有 LOCAL / LDAP / OIDC 身份；不同部门、角色与成员只看到被授权的模型与能力。

02

模型供给不再散落

企业集中提供并托管模型与供应商凭据，员工无需自行寻找服务商、保存密钥或反复配置连接。

03

成本、额度与风险可控

按组织、角色与成员管理模型访问与用量上限：五小时 / 日 / 周 / 月窗口，外加 RPM 与并发限制。

04

每一次使用都有迹可循

31 类审计事件与按人、按模型、按时间的用量账本，为成本分析、安全审计与持续优化提供依据。

BEFORE / AFTER

企业需要的不是更多账号，而是一套清晰的使用秩序

分散使用时接入 OwnDsh 后
账号与 API Key 由员工各自维护 企业身份一次登录，组织权限自动生效；供应商凭据只存在服务端
模型选择与数据边界难以统一 员工只能使用企业审核并授权的托管模型别名
成本、额度和异常使用不可见 用量账本与配额策略形成统一视图，超限直接返回可读的配额错误码
离职、转岗后的权限回收容易遗漏 停用成员或撤销设备即失效；审批与管理动作全部留下审计记录

SCENARIOS

当 Agent 从个人尝试走向组织使用

Scale

准备规模化推广

已有员工自发使用，希望从零散试验升级为统一、可复制的工作方式。

Govern

需要明确安全与数据边界

涉及内部资料与合规要求，需要知道谁在何时使用了哪些企业能力。

Operate

同时管理多个部门与模型

团队与模型持续增加，需要统一分配权限与额度，并理解真实使用效果。

DELIVERY

交付方式

私有化部署

在你的服务器或内网以 Docker Compose 部署；数据库、会话与构建产物都留在你的环境里。

对接既有体系

对接现有身份源（LDAP / OIDC）、模型平台与权限策略，不需要员工更换工作方式。

插件治理与分发

企业插件上传、发布、按人/组分配，客户端自主安装并回报安装结果。

升级与备份支持

版本升级、数据备份与恢复流程；镜像与依赖可离线交付。
