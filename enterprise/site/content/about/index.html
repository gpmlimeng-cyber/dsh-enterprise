ABOUT

真正拥有属于你的 Harness。

OwnDsh 是 DeepSeek Harness 的自托管团队控制面：把企业需要管的部分集中到平台，把员工需要的工作空间留在各自手里。 它不 fork 官方 Web UI，也不接管员工的工作区。

查看 GitHub 开始部署

RELATIONSHIP

与上游的关系

组件关系
DeepSeek Harness官方开源 Agent 运行时；OwnDsh 通过公开插件扩展点集成，不修改其源码
DSH Desktop社区桌面封装，由独立仓库构建；OwnDsh 可在其上以插件方式接入企业能力
OwnDsh Console / Server本项目的主体：GitHub OAuth 之外的完整企业治理面（身份、模型、授权、配额、插件、审计）
OwnDsh Desktop预装企业插件与运行环境的客户端，降低员工接入成本
隶属关系 OwnDsh 是独立项目，与 DeepSeek AI 或 Anywhere Labs 无隶属关系。上游名称、代码与商标归各自所有。

STATUS

当前阶段与已知限制

我们宁愿把限制写在官网上，也不想让你在部署之后才发现。

预发布阶段

接口与插件生态仍在演进；升级前请阅读发布说明并做好备份。

镜像平台

当前镜像目标为 Linux amd64；其他架构需自行构建。

默认 HTTP

默认以 HTTP 提供，平台自身不终止 TLS；正式环境建议前置反向代理并启用 HTTPS。

身份源

开箱为 LOCAL 账号；LDAP / OIDC 需要在控制台内配置后才能使用。

CONTRIBUTE

参与贡献

提交 Issue

部署问题、功能建议与缺陷都可以提到 GitHub Issues；附上 requestId 与服务端日志能显著加快定位。

改进文档

帮助中心与 API 参考都由仓库内容构建；发现描述与实现不一致，欢迎直接改内容并发起 PR。

贡献代码

服务端、控制台与插件均为独立模块，遵循各自的构建与检查命令。
