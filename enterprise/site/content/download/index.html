PLUGIN

已有官方 Harness / 社区 Desktop

先确保 pnpm 可直接执行（Harness 当前基线为 pnpm 11.7.0），再安装企业插件。

corepack enable corepack install --global pnpm@11.7.0 pnpm --version # Harness Web dsh plugin --profile web add --ignore-scripts dshent-plugin@next dsh --profile web # DSH Desktop dsh plugin --profile desktop add --ignore-scripts dshent-plugin@next
注意 只写 corepack pnpm … 是不够的：dsh plugin 的子进程仍会从 PATH 查找 pnpm。 判断标准很简单——直接运行 pnpm --version 能成功。安装后请重启对应 profile。

FIRST RUN

首次运行三步

01

填写 Server 地址

使用管理员提供的完整 HTTP(S) origin，例如 https://你的地址；不要附带 API 路径（不要写成 …/enterprise/…）。

02

企业登录

使用企业账号登录；若被要求设置新密码，说明初始口令是一次性的。

03

选择插件

在「DSH Enterprise 设置 → 插件」里自主安装管理员发布且对你可见的企业插件。

安全 供应商 API Key 不会下发到你的设备；每次模型请求都由平台网关重新校验身份、授权与额度。 Access Token 只存在 Host 内存，浏览器页面不会读取或保存它。
